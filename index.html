Отборочное задание

UZEX First Demo

Создали AI-ассистента для биржевой аналитики. С этим прототипом прошли в финал.

Подробнее об отборочном задании

Задача. Отвечать на вопросы о биржевых сделках на русском и узбекском по данным в чате.

Мой вклад. Формулировал задачи для прототипа и писал промпты для Claude Code.

Работа команды

  • Интегрировали Groq и резервный Gemini: LLM преобразует вопрос в план запроса.
  • Добавили проверку плана, SQL-расчёты и уточнение неоднозначных вопросов.
  • Подготовили импорт CSV и проверку валют, единиц измерения и результатов.
  • Результат. Прототип на учебном наборе из 500 000 вымышленных сделок; выход в финал UZEX.

Стек проекта. LLM API, Groq, Gemini, Python, SQL, Cloudflare D1 (SQLite), Drizzle ORM; React, TypeScript, Vinext / Vite, Tailwind CSS.

02 · Финальный этап

Основной хакатон

Intent — «Биржа намерений»

7–8 ноября 2026 · Ташкент, U-Enter

Биржевой MVP с голосовым и текстовым вводом поручений. LLM разбирает запрос, код проверяет числа и рассчитывает цену.

Мой вклад. Изучил работу UZEX и подготовил материалы для прототипа с Claude Code.

Мой вклад и работа команды

Задача. Дать покупателю возможность описать потребность обычными словами, подтвердить поручение и увидеть расчёт цены.

Мой вклад. Изучал работу UZEX и искал проблемы участников биржи в открытых источниках, на форумах и в Telegram. Использовал ChatGPT, Gemini и Perplexity. Передал собранные материалы в Claude Code для генерации идей и разработки прототипа.

Работа команды

  • Добавили голосовой и текстовый ввод на русском и узбекском: LLM извлекает параметры, код проверяет числа, пользователь подтверждает поручение.
  • Реализовали расчёт единой цены с учётом доставки и объединением небольших заказов.
  • Связали поручение с объяснением цены, демо-подписью, демо-эскроу и паспортом сделки.
  • Добавили автотесты чисел, правил распределения и независимости расчётного движка от LLM.
  • Результат. MVP для финала: от описания потребности до расчёта и объяснения цены. Подпись, платёж и реестры — демонстрационные.

Стек проекта. LLM API, Python, FastAPI, Pydantic, DuckDB, pandas, NetworkX; React, TypeScript, Vite, Tailwind CSS; pytest, Hypothesis, Vitest.

Наблюдения исследования и решения MVP

  • Для сравнения предложений нужны единицы, валюта и условия поставки, а не только название товара. В MVP предусмотрены уточнение параметров и подтверждение чисел. Тестовый портал UZEX
  • Помимо цены товара, в сделке есть сборы и условия расчётов. В MVP отдельно показаны сбор, задаток, доставка и объяснение итоговой цены. Тарифы UZEX

Выводы по открытым материалам; влияние решений на пользователей ещё не измерялось.
