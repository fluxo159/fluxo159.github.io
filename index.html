01 · Отборочный этап

Разработали AI-ассистента для биржевой аналитики

UZEX First Demo

Задача. Создать AI-ассистента, который отвечает на вопросы о биржевых сделках на русском и узбекском.

Мой вклад. Работал с Claude Code при разработке прототипа: формулировал задачи для AI-инструмента и писал промпты.

Работа команды

  • В команде интегрировали LLM через Groq и резервный Gemini: модель преобразует вопрос в структурированный план запроса.
  • Реализовали проверку плана, SQL-расчёты и возврат результата в чат.
  • Подготовили импорт CSV, обработку валют и единиц измерения, уточнение вопросов и контрольные проверки.
  • Результат. AI-прототип на 500 000 вымышленных сделок; команда вошла в число 23 финалистов.

Инструменты. LLM API, Groq, Gemini, Python, SQL, Cloudflare D1 (SQLite), Drizzle ORM; React, TypeScript, Vinext / Vite, Tailwind CSS.
